# Quad Loco

An individual project to build and test a quadruped locomotion task in Isaac Lab.

## Goal

First, load an Isaac Lab sample quadruped in simulation. Then develop a learning-based controller inspired by the DreamWaQ paper.

## Project structure

- `notes/` — learning notes and weekly reports
- `scripts/` — project run and training scripts
- `source/quad_loco/config/` — project configuration
- `source/quad_loco/networks/` — neural-network code
- `source/quad_loco/tasks/` — simulation task code
