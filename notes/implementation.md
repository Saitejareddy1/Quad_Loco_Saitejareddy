
# Quad Loco Implementation Plan

## Goal
Build a quadruped locomotion project in Isaac Lab, starting with an Isaac Lab sample quadruped.

## Development approach
- Develop the project on my laptop.
- Run and test it on the university computer.
- Keep the project in GitHub and back it up to an external SSD.
- Use the professor's Isaac Lab project-template instructions.

## Stages
1. Confirm the university's Isaac Lab version and available quadruped.
2. Create the matching Isaac Lab external project.
3. Load the quadruped in a basic simulation.
4. Add observations, actions, and rewards.
5. Add the actor, critic, and PPO training setup.
6. Add and test DreamWaQ-inspired components.
7. Document results and limitations.

## Current status
Project repository and initial folders created. Simulation code has not yet been tested.
